### What I'm working on

🎟️ **[EventCast](https://eventcast.online)**: a global event discovery platform. Search any city and see concerts, festivals and conferences pulled from live sources. For organizers, EventCast forecasts how much revenue an event could make at a given place and time. Selected as an ALPHA startup at Web Summit Lisbon 2026.

📊 **[event_demand_forecast](https://github.com/sarimyawaredu-crypto/event_demand_forecast)**: an open version of the idea behind EventCast's organizer forecasts. It models seasonal visitor demand in Stockholm from official accommodation statistics and turns it into an attendance and revenue estimate for a planned event.
